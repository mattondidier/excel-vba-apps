# Applications Excel VBA

🇬🇧 [English version](README.md)

**Des logiciels de gestion complets, construits en Excel VBA pour des petites entreprises : formulaires, base de données, calculs et tableaux de bord dans un seul classeur.**

Les fichiers Excel ne sont pas publics. Chaque dossier présente l'application : fonctionnalités, démonstration en GIF ou en vidéo, et choix techniques.

## Applications

| Application | Domaine | Ce qu'elle fait |
|-------------|---------|-----------------|
| [DIGESC](digesc-gestion-commerciale/README.fr.md) | Gestion commerciale | Achats, ventes, stock multi-dépôts, caisse, trésorerie et tableaux de bord |
